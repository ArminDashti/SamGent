# SamGent Android app

Visible Kotlin client for owned/consented devices.

## Open in Android Studio

1. **File → Open** → select this `android-app/` folder.
2. Let Gradle sync (wrapper JAR is generated by Android Studio on first open if missing).
3. Run on emulator or device.

## Server URL

- Emulator → host machine API: `http://10.0.2.2:3980`
- Physical device → your PC LAN IP: `http://192.168.x.x:3980`

## Flow

1. In WebUI **Devices**, create a device and copy the one-time API key.
2. On the phone: paste server base URL + API key → **Save connection**.
3. Grant permissions.
4. Sync now, or wait for periodic WorkManager sync / new-SMS trigger.
